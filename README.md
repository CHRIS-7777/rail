# Rail_pro – static ticket-screen UI demo

Static HTML/CSS/JS replica of a "Booking Details" ticket screen with a 5:00 countdown
(rolling digits, black/grey diamond panel), scrollable page and a random placeholder QR.
No backend, no build step, no network (fonts + QR lib are vendored).

All branding/data is fictional and the screen carries a **DEMO – NOT A VALID TICKET** marker.
It is a UI demo only and is not a real or usable ticket.

Run:  ./serve.sh   ->  http://localhost:8080   (or just open index.html)
Layout: index.html, css/style.css, js/app.js, vendor/ (fonts, qrcode.js), _ref/ (source recording + frames)
